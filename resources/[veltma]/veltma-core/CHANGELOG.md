# Changelog

## 0.6.0-rc.1

Release candidate for the Veltma Core foundation.

- finalized lifecycle and readiness state
- finalized server and client resource exports
- added safe lifecycle events and validated player transitions
- added server-only PostgreSQL foundation and database health reporting
- added typed RPC validation, safe errors, permissions, and rate limiting
- expanded unit and lifecycle stress coverage

This is not `v1.0.0`. Account and Character integrations must prove the public contracts in a real FXServer deployment before a stable release.
